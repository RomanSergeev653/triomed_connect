Для получения информации по записям пациента

Запрос:

https://{{adress:port}}/fmi/data/v1/databases/{{nameBase}}/layouts/time_free/script/find_record_shedule?script.param=375ХХХХХХХ|Иванов|Иван|Иванович|01.12.2025 (GET)

метод авторизации Bearer Token!


375ХХХХХХХ - телефон (формат 375ХХХХХХХ) телефон с кодом страны, но без + 
Иванов - Фамилия
Иван - Имя
Иванович - Отчество
01.12.2025 - дата (необязательный параметр) (формат дд.мм.гггг) ! Если дата меньше текущей - то будет пустое поле. Нелья просмотреть раньше текущей даты

Проверка идет по следующему сценарию:
1 - нет одного из параметра ( телефон; фамилия; имя)

Код отказа 700

Если параметры есть, то проверка второго уровня:
1 - есть номер телефона и фио, и они совпадают у одной карты пациента - ок
2 - есть номер телефона у другого пациента, есть ФИО (запрашиваемый) но у другой карты - при этом фамилии одинаковы - ок
3 - есть номер телефона у другого пациента, есть фио у другого пациента, фамилии не совпадают - отказ
 - нет номера телефона и/или нет ФИО пациента — отказ

Код отказа 800

Если все хорошо и ответ получен, то он приходит в такой последовательности:
id записи ; дата записи ; id врача ; время начала записи ; время окончания записи ; интервал записи

Если запись не одна, то разделитель ¶ (следующая строка)

Если нет записей код отказа 600

Для записи и перезаписи пациента

Запрос:

https://{{adress:port}}/fmi/data/v1/databases/{{nameBase}}/layouts/time_free/script/create_record_shedule_api?script.param=ХХХХХХХ|375|Иванов|Иван|Иванович|01.12.2025|08:00:00|09:00:00|12|33332|заболел (GET)

метод авторизации Bearer Token!

Для записи:
ХХХХХХХ - телефон (формат ХХХХХХХ) телефон БЕЗ кода страны, и без + 
375 - код телефона (формат 375), т.е. просто код страны, но без +
Иванов - фамилия
Иван - имя
Иванович - отчество
01.12.2025 - дата (формат дд.мм.гггг)
08:00:00 - время начала (формат чч:мм: сс)
09:00:00 - время окончания (формат чч:мм: сс)
12 - id врача

Для перезаписи нужно еще 2 параметра:
33332 - id записи для перезаписи
заболел - комментарий для перезаписи

Проверка идет по следующему сценарию:
1 - нет какого-то из параметров (телефон; код телефона; фамилия; имя; id врача; даты; времени начала; времени конца записи)

Код отказа 500

Если это перезапись (т.е. есть id перезаписи) и нет комментария

Код отказа 500 (могу поменять если надо)

Если параметры есть, то проверка второго уровня:

1 - если пациента нет в базе (т.е. не нашли ни телефон, ни ФИО), создаем новую запись - ок
2 - если нашли номер, но ФИО не совпадает больше чем на 80% - отказ 800
3 - если не нашли номер, но нашли полное соответствие ФИО - ок

Ответ приходит с кодом записи в result будет дополнительное слово "record: "


!ВНИМАНИЕ!
Если время между запросами превышает 15 минут, то нужно повторно делать авторизацию на сервере для получения нового токена!
